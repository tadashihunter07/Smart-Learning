🌀 LingoPath AI - Innovation & Design Thinking Project 2026
📖 Project Overview
LingoPath AI is a smart language learning solution designed to solve the common issues of information overload and lack of direction among students. By leveraging AI technology, we provide a personalized and structured learning journey.

✨ Key Features (Prototype)
Our functional prototype demonstrates the core principles of our Design Thinking process:

Daily Learning Roadmap: Personalized "Today's Roadmap" to eliminate confusion about what to study next.

AI Speaking Mentor: Real-time pronunciation analysis and instant feedback using simulated AI logic.

Smart Flashcards: Vocabulary system based on Spaced Repetition to enhance long-term memory.

Progress Tracking: Gamified elements like "Daily Streaks" to maintain student motivation.

🛠️ Technology Stack
To ensure a high-fidelity and feasible prototype, we used:

HTML5: For a structured and semantic web layout.

CSS3: Featuring a modern Gradient UI (Purple & Blue) and Responsive Design for both Mobile and Desktop.

JavaScript: To handle interactive logic, tab navigation, and AI feedback simulations.

🚀 How to Run the Prototype
Download or clone the project folder.

Open the folder in VS Code.

Right-click index.html and select "Open with Live Server" (or simply double-click the file to open it in your browser).

Navigate through the tabs (Home, Learn, Stats, Profile) using the bottom navigation bar.

🧪 Testing & Refinement
During our Testing phase, we identified that users preferred a more streamlined interface. Based on this insight, we refined the UI by:

Adding a sticky navigation bar for easier access.

Implementing a "Flip" animation for Flashcards to provide immediate visual feedback.
